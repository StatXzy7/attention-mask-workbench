# attention-mask-workbench

Linux CPU 上的**本地注意力掩码工作台**：真实计算稀疏注意力输出，并与稠密参考逐元素对比。零第三方运行时依赖（仅使用 Node.js 内置模块）。

## 运行

```bash
npm run build   # 语法检查 + 核心冒烟计算
npm test        # 24 个可自行结束的 node:test 用例（数值/掩码/状态恢复/HTTP）
npm start       # 默认 http://127.0.0.1:5173/
npm start -- --host 0.0.0.0 --port 8080
npm start -- --host=127.0.0.1 --port=0   # 端口 0 = 动态端口，启动时打印实际地址
```

要求 Node.js >= 20（开发环境为 Node 22）。

## 计算流程

1. 内置小型多头数据（2 头 × 4 位置，dk=3，dv=2），也可在页面手工编辑 Q/K/V 的三维 JSON。
2. 非负特征映射固定为 `φ(x) = max(x, 0) + 1`。
3. 将键位置划分为若干连续半开区间，估计分数为 `φ(q_i) · mean(φ(k_j), j ∈ 区间)`；因果模式下区间只取不超过 `i` 的键前缀，完全位于未来的区间不参与。
4. 每个头的估计分数按区间和归一化。
5. 按归一化分数降序选区间（并列时按头、再按区间位置稳定排序）：
   - 逐头选择：每头各自获得预算；
   - 跨头共享预算：同一查询的所有头候选放在一起竞争同一份预算。
6. 选中区间映射回原始键位置并去重，预算超上限截断为区间数。
7. 仅在保留位置上执行**稳定的缩放点积注意力**（`softmax((QK^T)/√dk)`，减最大值防溢出）；稠密参考在全部可见位置上同样计算。
8. 输出保留数量、最大绝对误差、聚合相对二范数误差（`‖稀疏-稠密‖₂/‖稠密‖₂`）。
   - 零预算：稀疏输出为零向量，界面显示空掩码状态。
   - 参考范数为零：稀疏也为零记相对误差 0，稀疏非零记 `∞`，语义明确。

## SVG 同步视图

每个头三条逐查询 × 键位置的热力轨道：估计分数（区间分数映射到位置）、实际稀疏掩码（0/1）、稠密注意力权重。悬停格点可见原始估计分数与稀疏权重；因果禁止位置单独标记。

## 校验与错误语义

- 拒绝 `NaN/Infinity` 等非有限数；拒绝空数组、非三维、头数/位置数/特征维度不一致。
- 参数修改和 Q/K/V 编辑都先试算：失败时保留上次有效结果并展示错误，不覆盖数据。

## 代码结构

- `src/core.js`：特征映射、区间划分、估计归一化、选择/去重、稳定 softmax、稀疏与稠密注意力及误差度量（浏览器与 Node 同构）。
- `src/store.js`：页面共享状态机（参数变更、编辑应用、错误恢复、订阅通知；Node 测试直接驱动它）。
- `src/server.js`：零依赖静态服务器，支持 `--host/--port` 与端口 0。
- `web/`：`index.html`、`styles.css`、`app.js`（SVG 与表格渲染）。
- `test/`：`core.test.js`（13 个数值/掩码/语义用例）、`store.test.js`（8 个参数与错误恢复用例）、`server.test.js`（3 个 HTTP 用例）。
