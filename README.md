# 本地稀疏注意力掩码工作台（Linux / CPU）

一个零第三方运行时依赖的本地工作台：**真正计算稀疏注意力输出**，并与同一组 Q/K/V 上的
稠密参考逐元素对比。使用内置小型多头数据，也支持手工编辑每个头的 Q、K、V。

## 运行

```bash
npm install   # 无需安装任何依赖；仅为兼容习惯
npm run build # 语法检查全部 JS，并把可运行产物暂存到 dist/
npm test      # 运行 30+ 个会自行结束的断言测试（node:test）
npm start     # 默认 http://127.0.0.1:8080
```

启动参数：

```bash
node server.js --host 0.0.0.0 --port 5173
node server.js --port=0        # 0 = 由操作系统动态分配端口，启动后打印真实地址
HOST=127.0.0.1 PORT=9000 npm start
```

打开浏览器访问输出的地址即可。

## 算法语义

1. **特征映射（固定，非负）**：`φ(x) = max(x, 0) + 1`，逐元素应用于 Q 与 K。
2. **连续键区间**：把每头的 `nk` 个键位置均衡切分为 `B` 个连续区间（长度相差至多 1）。
3. **估计分数**：对查询 `i`，估计分数 = `φ(q_i) · mean(φ(k_j) over j in 区间可见部分)`。
   - 因果模式下，区间被裁剪到只含 `j ≤ i` 的可见部分；完全位于未来的区间不可见、分数为 0。
4. **归一化**：每头的区间估计分数按该头所有可见区间分数之和归一化。
5. **排序与预算**：归一化分数降序；分数并列（含浮点容差）时稳定地按“头 → 区间位置”排序。
   - 逐头模式：每个头独立分配 `预算` 个区间。
   - 共享模式：同一查询的所有头池化后共同消耗 `预算` 个“(头, 区间)”名额。
6. **映射回去重**：选中区间映射回原始键位置，位置集合去重后升序排列，得到二值掩码。
7. **真实稀疏注意力**：仅在保留位置上执行稳定缩放点积注意力
   `softmax((φ(q)·φ(k))/√d_k)`，并在保留子集上重新归一化；V 保持原值。
8. **稠密参考**：在同一因果可见集合上用同样的稳定 softmax 计算，但保留全部可见键。

指标在拼接后的全部头上聚合：

- **最大绝对误差** `max |稀疏 - 稠密|`
- **相对二范数误差** `‖稀疏 - 稠密‖₂ / ‖稠密‖₂`
- 当稠密参考范数 ≤ `1e-12` 时，**不产生 NaN**：标记 `refNormIsZero`，
  并把“相对误差”回退报告为绝对差范数 `‖Δ‖₂`。

## 边界与错误语义

- **预算超上限截断**：逐头模式上限为 `B`；共享模式上限为 `头数 × B`；界面会提示截断。
- **区间数超上限截断**：`B > nk` 时截断到 `nk`。
- **零预算**：所有头返回零向量，掩码为空，界面显示“空掩码状态”。
- **非有限数 / 形状冲突**：解析或校验立即拒绝（NaN、Infinity、错排行、q/k 维度不一致、
  k/v 位置数不一致、跨头 q/k 数量不一致等）。
- **错误恢复**：被拒绝的编辑不会覆盖上一次有效结果；草稿文本保留以便修改，修正后即时恢复。

## 界面

- 控件：区间数 `B`、选择预算、因果开关、跨头共享预算开关、查询位置切换、重置。
- 三个同步 SVG 面板：
  1. 估计分数柱状图（黄色描边标记被选区间，悬停可见原始/归一化分数）；
  2. 实际掩码（保留 / 可见未选 / 因果未来）；
  3. 稠密与稀疏权重热力图（格内为权重数值）。
- 输出对照表逐维列出稠密、稀疏与差值；顶部展示保留对数、最大绝对误差、相对二范数误差等。

## 目录结构

```
server.js            进程入口（--host/--port，端口 0 动态分配）
src/http-app.js      静态资源 handler 与参数解析（可独立测试，不自动监听端口）
src/core.js          特征映射、区间估计、稳定注意力、选择/去重/指标（浏览器与 Node 共用）
src/data.js          内置多头数据与矩阵文本解析
src/store.js         界面状态、参数变更重算、非法编辑不覆盖上次有效结果
web/                 index.html / style.css / app.js / render.js（SVG）
tests/               node:test：数值、掩码、因果、去重、错误恢复、参数变更、服务器
scripts/build.js     构建（语法检查 + dist 暂存 + build-manifest.json）
```

## 依赖

主要第三方运行时依赖：**0 项**（仅使用 Node 内置 `http`、`fs`、`node:test` 等）。
要求 Node.js ≥ 18（测试使用内置 `fetch` 与 `node:test`）。
